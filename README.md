# 🎯 Python Daily Challenge Generator

A fun and interactive **Daily Challenge Generator** desktop application built with **Python and Tkinter**.

The application provides random challenges from different categories and difficulty levels, allowing users to test their knowledge, solve problems, and track their scores.

---

## ✨ Features

- 🎲 Generate random challenges
- 🧠 Logic challenges
- 💻 Coding challenges
- 🔢 Math challenges
- 🎯 General knowledge challenges
- ⭐ Easy, Medium, and Hard difficulty levels
- 💡 Hint system
- ✅ Answer checking
- 🏆 Score tracking
- 📊 Attempt counter
- 🔄 Reset score
- 📅 Displays the current date
- ⌨️ Enter key shortcut for checking answers
- 🌙 Clean dark-themed interface
- 🚫 No external packages required

---

## 🛠️ Technologies Used

- Python 3
- Tkinter
- Random Module
- Datetime Module
